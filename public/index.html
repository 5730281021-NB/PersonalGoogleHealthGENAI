Deploy & Setup Guide

From zero to running on Vercel.

1
Push to GitHub & import to Vercel
Upload this folder to a GitHub repo, then go to vercel.com/new and import it. Vercel auto-detects the config.
2
Add your Gemini key as an env variable
Get a free key at aistudio.google.com/apikey. In Vercel → Project → Settings → Environment Variables, add GEMINI_API_KEY with your AIza... key. Redeploy after adding.
3
Create a Google Cloud project
console.cloud.google.com → New Project. Enable the Google Health API under APIs & Services → Library.
4
Set up OAuth consent + client
OAuth consent screen → External → add your Gmail as a Test User. Then Credentials → Create OAuth Client ID → Web application. Add your Vercel URL (shown on the Setup page) to Authorized redirect URIs.
5
Add health scopes
In OAuth consent → Scopes, add googlehealth.activity_and_fitness.readonly, googlehealth.health_metrics_and_measurements.readonly, and googlehealth.sleep.readonly.
6
Connect & go
Open your deployed site → Setup → paste your Client ID → Connect Google Health → Refresh Data → start chatting.
ℹ Security note: Your Gemini key stays server-side via the /api/chat serverless function. The browser never sees it.
